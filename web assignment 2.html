Steps to Create a Website

Things You Need (Unordered List)

  • A code editor (like VS Code or Notepad)
  • A web browser (like Brave, Chrome, or Firefox)
  • Your media files (images, audio, video)
  • A GitHub account to host your repository

Step-by-Step Process (Ordered List)

  1. Create a new project folder named "html-portfolio-lab".
  2. Create the root file and name it index.html.
  3. Write the standard HTML structure (html, head, and body tags).
  4. Add your website content using headings, lists, and tables.
  5. Push and synchronize all your files to GitHub.

Common HTML Tags Used in Web Design

HTML Tag Element Name Purpose on the Website
h1 to h6 Headings Displays titles and subheadings on the webpage.
p Paragraph Holds standard blocks of text on the page.
